# Recruiter Project Summary

## Project title
Airbnb NYC Market Analysis

## One-line description
Analyzed 48,895 Airbnb listings using Python, statistical testing, and geospatial analysis to identify pricing, demand, and location trends across New York City.

## Resume-ready bullet points
- Analyzed 48,895 Airbnb listings using Python, Pandas, Seaborn, SciPy, and GeoPandas to identify pricing, demand, and location-based trends across five New York City boroughs.
- Performed data cleaning, descriptive analysis, ANOVA, independent t-testing, correlation analysis, and geospatial visualization to validate differences in pricing across room types and boroughs.
- Translated analytical findings into business recommendations related to pricing strategy, listing visibility, guest engagement, and availability management.

## Interview talking points
1. The project began as a team academic analysis, but the repository was restructured into a reproducible business-focused workflow.
2. Missing review values were handled carefully rather than dropping all no-review listings.
3. Statistical testing was used to support, not replace, business interpretation.
4. The strongest insight was that pricing strategy should be segmented by both borough and room type.
5. The next logical step would be an interactive dashboard or price-prediction model.
