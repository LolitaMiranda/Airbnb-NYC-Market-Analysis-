# Airbnb-NYC-Market-Analysis-
An exploratory data analysis (EDA) project on the Airbnb NYC Open Data dataset using Python. The project examines pricing, room types, neighborhood trends, and listing availability through data cleaning, visualization and statistical analysis to uncover insights into the short-term rental market.
